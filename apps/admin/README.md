# لوحة تحكم الإدارة — لم تُبدأ بعد

ستُبنى لاحقاً كـFlutter Web (حسب SRS القسم 2.4: "لوحة تحكم الإدارة:
تطبيق ويب")، معتمدة جزئياً على [packages/mashwar_core](../../packages/mashwar_core)
(الثيم، معالجة الأخطاء) دون التقيّد بودجتات الجوال (`AppButton`/`AppCard`)
إن لم تناسب واجهة أدمن كثيفة البيانات.

يشمل حسب SRS: مراجعة وتوثيق المزارع، إدارة الشكاوى والمنازعات، إدارة
العمولات والاشتراكات، إدارة المحتوى، تقارير النظام (FR-ADM).
