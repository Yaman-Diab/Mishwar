# تطبيق صاحب المزرعة — لم يُبدأ بعد

سيُبنى لاحقاً (Flutter، جوال) بنفس أسلوب [apps/customer](../customer):
Clean Architecture + Cubit + get_it/injectable، معتمداً على
[packages/mashwar_core](../../packages/mashwar_core) للثيم ومعالجة
الأخطاء والودجتات المشتركة.

يشمل حسب SRS: إضافة وإدارة المزارع، التقويم والجدولة، إدارة طلبات
الحجز، الإحصائيات، إدارة الأسعار الموسمية (FR-OWN).

`features/auth` هنا لازم تُبنى من جديد (لا تُشارك مع تطبيق العميل) —
حسب SRS الفرق البسيط: تسجيل صاحب المزرعة يتضمّن بيانات تعريفية إضافية
(اسم النشاط، معلومات التواصل الداخلي) غير الموجودة بتسجيل العميل.
